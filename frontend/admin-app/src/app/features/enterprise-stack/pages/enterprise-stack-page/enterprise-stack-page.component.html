Distributed Architectural Blueprint

1. Edge API Gateway Layer

Spring Cloud Gateway acts as the single unified ingress point on port 8080. It handles rate limiting, pre-flight CORS headers, Clerk Bearer token validation, and non-blocking routing to backend microservices.

2. Transactional Outbox Pattern

When products or orders are updated, changes write atomically to MySQL and an outbox_events table within the same transaction. A scheduled worker reads pending events every 5 seconds and dispatches them to Apache Kafka KRaft (product.events.v1).

3. Clerk Identity & Access Management

Replaced Keycloak with Clerk IAM. Frontends authenticate with Google Workspace or email credentials, obtaining RS256 JWT tokens. Spring Security's ClerkRoleConverter maps claims to ROLE_PRODUCT_MANAGER and ROLE_ADMIN authorities.

4. Distributed Sagas & Ephemeral Storage

Checkout orchestrates multi-step sagas across Pricing, Inventory, and Payment. Redis manages 15-minute stock reservation TTL locks preventing race conditions, while Elasticsearch powers full-text fuzzy product search.
